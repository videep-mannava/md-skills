# Markdown Learning Journal

## Overview

Aperture is a software meant to help increase accessibility for desktop applications.

## Features

- Text to Speech integration for any desktop app.
- Real time subtitles and transcription using OpenAI Whisper.
- Keyboard navigation to move through UI with tab and enter keys.

## Prerequisites

Must have either Windows Operating System, or Mac Silicon. Other OSs are not yet supported.

## Installation

Run these commands in a terminal to download this repository, then enter its folder:

```bash
git clone https://github.com/videep-mannava/skills-communicate-using-markdown.git
cd skills-communicate-using-markdown
```

Open `day-1.md` in your editor to confirm the journal is present. No build or dependency installation is required.
